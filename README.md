# **Spear Game**

This is a simple recreation of the Undertale green soul minigame seen when fighting against Undyne.

**Features**
- Saving for color choices, difficulty, and an easy main menu to access all the forementioned settings
- Easy to understand controls (WASD) and scoring system that rewards fast paced gameplay
- Spears that fly at you!

**Built With**:
C# and the Unity Engine

**To Run It**:
- Pull the repo at https://github.com/bigmmg/Spear-Game.git
